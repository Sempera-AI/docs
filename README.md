# Sempera developer documentation

The Mintlify project for the Sempera developer documentation. Every file here is generated
and replaced on each publish, so an edit made here is lost. Edit the pages in
`04-delivery/api-docs/` of the main Sempera repository and publish again with
`06-tools/publish-mintlify.py`. The API reference is built by Mintlify from
https://api.sempera.org/openapi.json.

Each publish commit names the source commit it was built from.
