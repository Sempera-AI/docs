Seven open-source projects sit on top of the API. Each is MIT licensed, public in the `Sempera-AI` organisation on GitHub, uses your workspace API key, and calls only routes that `https://api.sempera.org/openapi.json` lists. The TypeScript and Python SDKs, the command line, the MCP server, the agent skills kit and the n8n nodes are published on npm, and the Python SDK is on PyPI. The examples are only in their repository ([Migration and changelog](/changelog)).

Create the key in the Sempera App under Settings, API keys, and give it only the scopes the tool needs ([Authentication and credentials](/authentication)).

## Client libraries

### TypeScript SDK

[Sempera-AI/sempera-node](https://github.com/Sempera-AI/sempera-node) is the official TypeScript client: one typed method per operation in the contract, plus retries, idempotency keys, paging and webhook signature verification. Node 22.18 or newer. Usage is in [TypeScript and Python SDKs](/sdks).

```bash
npm install @sempera/sdk
```

### Python SDK

[Sempera-AI/sempera-python](https://github.com/Sempera-AI/sempera-python) is the official Python client, standard library only, with the same retries, idempotency keys, paging and webhook verification. Python 3.9 or newer. Usage is in [TypeScript and Python SDKs](/sdks).

```bash
pip install sempera
```

## Command line

[Sempera-AI/sempera-cli](https://github.com/Sempera-AI/sempera-cli) is the `sempera` command (`@sempera/cli`): list agents, read calls and conversations, check numbers, place a call or send a text, and verify webhook signatures from a terminal or a script. Add `--json` to any command for the API's own answer. Node 20 or newer.

```bash
npm install -g @sempera/cli
sempera login
sempera agents list
```

## AI and coding agents

### MCP server

[Sempera-AI/sempera-mcp](https://github.com/Sempera-AI/sempera-mcp) (`@sempera/mcp`) is a Model Context Protocol server that runs on your machine over stdio. It lists the same tools as Sempera's hosted MCP endpoint ([MCP for coding agents](/connect-mcp)) and sends each call there with your API key, so the hosted scope, role and approval checks apply. Enable phone writes with `--allow-writes` and workspace management writes with `--allow-management-writes`. Both default to off. Node 20 or newer.

### Agent skills and editor rules

[Sempera-AI/sempera-ai](https://github.com/Sempera-AI/sempera-ai) (`@sempera/ai`) holds skills, plugin manifests and editor rules that teach a coding agent to build and publish an agent, place a call or send a text with consent, read conversations, set up a number and debug a call. Install it with `npm install @sempera/ai`. [Supported clients](/supported-clients) lists each client and whether a real connection has been recorded.

## Automation

[Sempera-AI/n8n-nodes-sempera](https://github.com/Sempera-AI/n8n-nodes-sempera) (`n8n-nodes-sempera`) adds n8n community nodes: place a call, send a text, read calls, list agents, and start a workflow when a signed webhook arrives. In n8n, install it under Settings, Community nodes. The trigger verifies every delivery as [Webhooks](/webhooks) describes. Node 20 or newer.

## Examples

[Sempera-AI/sempera-examples](https://github.com/Sempera-AI/sempera-examples) has small runnable examples in Node, Python and curl, each doing one job: place a call, receive and verify webhooks, text without breaking opt-outs, check a connected calendar and then place a booking call, and start a batch from a CSV. They need no packages. They are not published to npm or PyPI.

## Which one to use

| You want to | Use |
| --- | --- |
| Call the API from a server | The TypeScript or Python SDK, or plain HTTPS ([Getting started](/getting-started)) |
| Script or inspect a workspace by hand | The command line |
| Let an assistant or coding agent work with Sempera | The MCP server and the agent skills, or the hosted MCP endpoint |
| Start a no-code workflow on a call | The n8n nodes |
| Copy a working starting point | The examples |
