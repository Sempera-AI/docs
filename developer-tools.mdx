Seven open-source projects sit on top of the API. Each is MIT licensed, public in the `Sempera-AI` organisation on GitHub, uses your workspace API key, and calls only routes that `https://api.sempera.org/openapi.json` lists. None is on npm or PyPI yet, so today you install each one from its repository ([Migration and changelog](/changelog)).

Create the key in the Sempera App under Settings, API keys, and give it only the scopes the tool needs ([Authentication and credentials](/authentication)).

## Client libraries

### TypeScript SDK

[Sempera-AI/sempera-node](https://github.com/Sempera-AI/sempera-node) is the official TypeScript client: one typed method per operation in the contract, plus retries, idempotency keys, paging and webhook signature verification. Node 22.18 or newer. Usage is in [TypeScript and Python SDKs](/sdks).

```bash
npm install github:Sempera-AI/sempera-node
```

### Python SDK

[Sempera-AI/sempera-python](https://github.com/Sempera-AI/sempera-python) is the official Python client, standard library only, with the same retries, idempotency keys, paging and webhook verification. Python 3.9 or newer. Usage is in [TypeScript and Python SDKs](/sdks).

```bash
pip install git+https://github.com/Sempera-AI/sempera-python
```

## Command line

[Sempera-AI/sempera-cli](https://github.com/Sempera-AI/sempera-cli) is the `sempera` command: list agents, read calls and conversations, check numbers, place a call or send a text, and verify webhook signatures from a terminal or a script. Add `--json` to any command for the API's own answer. Node 20 or newer.

```bash
git clone https://github.com/Sempera-AI/sempera-cli.git
cd sempera-cli && npm install && npm link
sempera login
sempera agents list
```

## AI and coding agents

### MCP server

[Sempera-AI/sempera-mcp](https://github.com/Sempera-AI/sempera-mcp) is a Model Context Protocol server that runs on your machine over stdio. It lets an assistant read your agents, calls, conversations and numbers, and place a call or send a text only when you turn writes on. Sempera also hosts an MCP endpoint over HTTP ([MCP for coding agents](/connect-mcp)); this package is the local alternative.

### Agent skills and editor rules

[Sempera-AI/sempera-ai](https://github.com/Sempera-AI/sempera-ai) holds skills, plugin manifests and editor rules that teach a coding agent to build and publish an agent, place a call or send a text with consent, read conversations, set up a number and debug a call. [Supported clients](/supported-clients) lists the clients Sempera has checked.

## Automation

[Sempera-AI/n8n-nodes-sempera](https://github.com/Sempera-AI/n8n-nodes-sempera) adds n8n community nodes: place a call, send a text, read calls, list agents, and start a workflow when a signed webhook arrives. The trigger verifies every delivery as [Webhooks](/webhooks) describes.

## Examples

[Sempera-AI/sempera-examples](https://github.com/Sempera-AI/sempera-examples) has small runnable examples in Node, Python and curl, each doing one job: place a call, receive and verify webhooks, text without breaking opt-outs, book through a connected calendar, and start a batch from a CSV. They need no packages.

## Which one to use

| You want to | Use |
| --- | --- |
| Call the API from a server | The TypeScript or Python SDK, or plain HTTPS ([Getting started](/getting-started)) |
| Script or inspect a workspace by hand | The command line |
| Let an assistant or coding agent work with Sempera | The MCP server and the agent skills, or the hosted MCP endpoint |
| Start a no-code workflow on a call | The n8n nodes |
| Copy a working starting point | The examples |
