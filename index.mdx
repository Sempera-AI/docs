Sempera builds and operates AI phone agents ("AI employees") for independent businesses. The [Sempera API](/api-overview) at `https://api.sempera.org/v1` lets a developer create an Agent, configure and publish it, attach tools, knowledge and a phone number, open Web voice sessions, and read every conversation. One hostname, one credential model, path-versioned under /v1.

## Make your first request

<CodeGroup>

```bash cURL
curl https://api.sempera.org/v1/me \
  -H "Authorization: Bearer sempera_sk_..."
```

```js Node
// Node 18 or newer: fetch is built in
const res = await fetch("https://api.sempera.org/v1/me", {
  headers: { Authorization: `Bearer ${process.env.SEMPERA_API_KEY}` },
});
console.log(res.headers.get("x-request-id"), await res.json());
```

```python Python
import json, os, urllib.request

req = urllib.request.Request(
    "https://api.sempera.org/v1/me",
    headers={"Authorization": f"Bearer {os.environ['SEMPERA_API_KEY']}"},
)
with urllib.request.urlopen(req) as res:
    print(res.headers["X-Request-Id"], json.load(res))
```

</CodeGroup>

The answer names the credential: its kind, workspace, role and scopes. The full journey is in [Getting started](/getting-started).
