Sempera builds and operates AI phone agents ("AI employees") for independent businesses. The Sempera API at https://api.sempera.org/v1 lets a developer create an Agent, configure and publish it, attach tools, knowledge and a phone number, open Web voice sessions, and read every conversation. One hostname, one credential model, path-versioned under /v1.
