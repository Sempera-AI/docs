Custom model setup is in limited testing. Contact Sempera to confirm whether your workspace can test a custom model connection. Check the [live OpenAPI contract](https://api.sempera.org/openapi.json) for the supported developer operations.

A connection test checks whether Sempera can reach an endpoint and get a compatible response. It does not save a credential, publish an agent or place a call. Confirm that a published agent uses the chosen model before relying on it in production.

Use a public HTTPS base address without credentials, a query or a fragment. Sempera appends the chat completions path. Provide your key only in the connection form and use a key dedicated to Sempera. The key is write-only. See [Secrets and request signing](/secrets-and-signing) for secret storage and [Agents](/agents) for publishing and versions.
