An agent's draft takes these settings through the same publish step as every other call setting ([Agents](/agents)). They are saved under the same names in the agent's published call settings, and the draft and published reads of the agent show them.

| Setting | Values | What it does |
| --- | --- | --- |
| `noise_cancellation` | `true`, `false`, or an object with exactly `web`, `inbound` and `outbound`, each `off`, `noise` or `noise_and_voices` | Reduces background sound before the caller is recognised. `true` uses the existing noise filter on every channel. The `calls.noise_cancellation` read stays a boolean for older screens, and `calls.noise_cancellation_channels` holds the level for each channel. |
| `keywords` | a list of up to 50 terms | Names and terms the recogniser should listen for. The limit depends on the recognition engine in use: `calls.keywords_max` shows it for the engine the agent uses, and an engine that takes no keywords reports 0. A new edit past the limit is refused with that limit. Keywords already published are not rewritten. |
| `max_wait_when_unsure_ms` | `null`, or a whole number from 600 to 4000 | The longest the agent waits for more speech when it is unsure the caller has finished. `null` is automatic: the response wait plus 500 ms. Not set keeps the previous timing. |
| `ignore_phrases` | up to 50 phrases of 1 to 40 characters | Short phrases such as "uh huh" that do not interrupt the agent. Phrases are trimmed and compared without regard to case, and duplicates are dropped. A longer sentence that contains a phrase still counts as an interruption. |
| `echo_guard` | an object with exactly `web`, `inbound` and `outbound`, each `true` or `false` | For the first 3 seconds after the agent starts speaking, uncertain overlapping speech is ignored. Speech that carries on for the interruption sensitivity window is accepted. Not set means off on all three channels. |

`noise_and_voices` is saved, but at present it applies the same noise reduction as `noise`; the call record says so. Ignore phrases and echo guard make interruptions wait for the final recognised words, because a whole phrase cannot be told from partial words.
